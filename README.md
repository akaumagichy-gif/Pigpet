# 旋转猪猪桌宠 (PigPet)

一只绕自身**逆时针旋转**的透明小猪，做成极小的**置顶桌宠窗口**。可以像捏弹弓一样拖拽它、让它变形，松手后沿反方向「弹射」出去，撞墙、减速、最后悬空停下——但它是无重力的，还会一直转，随时可以再抓起来。

纯 Python + PyQt5，单文件，开箱即用。

---

## 特性

- **透明置顶小窗**：无边框、不占任务栏、背景全透明，始终浮在最上层。
- **弹弓玩法**：按住猪猪，以你**点到的像素点**为轴心，把它整体旋转 + 拉伸 + 压扁（像捏住一点猛拽，越拖越怪诞）→ 松手沿反方向弹射。
- **无重力物理**：直线飞行、每次撞墙掉速（带空气阻力），几番后悬空停下；停下后仍在旋转，可再抓。
- **静止自动弹跳**：放它不管一段时间（默认 6 秒），猪猪会自己「受惊」——朝随机方向弹射一下，又跑去撞墙、减速、停住。全程仍可随时抓住。
- **多屏支持**：启动时在鼠标所在屏幕居中生成；右键 →「放置到屏幕」→ 选任意屏幕。
- **系统托盘**：通知区右下角有托盘图标，可一键显示 / 隐藏 / 退出。
- **单文件**：核心逻辑全在一个 `pigpet.py` 里，常量集中在顶部，好调。

## 运行

**方式一：一键启动（推荐，无控制台）**

双击 `start_pig.bat`。脚本会优先用 `pythonw` 启动（不弹黑框），若没有则退回 `python`。

**方式二：命令行**

```bash
python pigpet.py
```

启动后，猪猪会出现在当前鼠标所在屏幕正中。

## 操作方法

| 操作 | 效果 |
| --- | --- |
| **按住左键（抓住猪）** | 进入拖拽状态，开始记录拉伸 |
| **按住并拖动** | 以按下时点到的像素为轴心，把猪整体旋转 + 沿拖动方向拉伸 + 垂直压扁（越拖越变形） |
| **松开左键（释放）** | 沿拉伸的反方向弹射出去；拉得太小则原地不动 |
| **右键** | 弹出菜单：显示/隐藏、放置到屏幕、退出 |
| **托盘图标 左键单击/双击** | 显示 / 隐藏猪猪 |
| **Esc** | 退出程序 |

**物理规律**

- 无重力，直线飞行；
- 每次撞屏幕边缘，速度 × `RESTITUTION`（默认 0.95，明显掉速）；
- 空气阻力每帧 × `AIR_DRAG`（默认 0.995），保证最终能停下；
- 速度低于 `STOP_SPEED` 即判定为「悬空停下」，停住后仍在原地旋转，可再次抓住；
- 静止超过 `IDLE_NUDGE_MS`（默认 6 秒）且没被抓着，猪猪会朝随机方向自己「受惊」弹一下（初速 `NUDGE_SPEED`），之后照常撞墙 / 减速 / 停下。

---

## 多屏支持

- 启动时在**鼠标所在屏幕**居中生成；
- 撞墙反弹以猪猪**当前所在的屏幕**边界为准；
- 右键 →「放置到屏幕」→ 选择任意屏幕，猪猪会移动过去并清零速度、重置飞行状态。

## 可调参数

所有常量都在 `pigpet.py` 顶部 `# ---------------- 可调常量 ----------------` 区块：

| 常量 | 默认值 | 说明 |
| --- | --- | --- |
| `W, H` | `160, 160` | 窗口大小（正方形） |
| `LAUNCH_K` | `0.6` | 发射力度系数（越大射得越远/越快） |
| `MIN_SPEED` | `3.0` | 最小发射速度（避免原地不动） |
| `TIMER_INTERVAL` | `16` | 物理帧间隔 ms（≈60fps） |
| `SPIN_SPEED` | `90` | 猪旋转播放速度 %（100=原速，越小越慢） |
| `MAX_STEP` | `30.0` | 单次物理子步最大位移，防止高速穿墙 |
| `RESTITUTION` | `0.95` | 撞墙反弹系数（每次撞墙速度乘法衰减） |
| `AIR_DRAG` | `0.995` | 每帧空气阻力（让它最终能停下） |
| `STOP_SPEED` | `1.0` | 低于此速度即视为停下 |
| `MAX_PULL` | `130.0` | 拉伸上限 px（拉过一点就不再增大力度） |
| `IDLE_NUDGE_MS` | `6000` | 静止这么久(ms)后自动「受惊」弹射（`0` = 关闭） |
| `NUDGE_SPEED` | `100.0` | 随机弹射的初速度 px/tick（越大越猛） |

## 技术要点

- **透明置顶窗**：`Qt.FramelessWindowHint | Qt.WindowStaysOnTopHint | Qt.Tool` + `Qt.WA_TranslucentBackground`。
- **动画**：`QMovie` 播放 GIF，`setScaledSize` 缩放，`setSpeed` 控制转速，`frameChanged` 触发重绘。
- **变形绘制**：拖拽时对 `currentPixmap()` 做「平移-旋转-缩放」的组合变换，并计算变形后包围盒，统一缩放 `f` 让整只猪始终留在窗口内。
- **物理**：固定步长子步（`MAX_STEP`）防止高速穿墙；边界反弹 + 空气阻力；亚像素精度位置（`QPointF`）。
- **托盘**：无系统托盘时回退为仅右键菜单；隐藏窗口但不退出（`setQuitOnLastWindowClosed(False)`）。
